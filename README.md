# Little Learner

  Working through the exercises in *The Little Learner: A Straight Line to Deep Learning*.


  ## Layout

  One Racket file per chapter, `ch-0.rkt` through `ch-15.rkt`.

  ## Running

  Written in Racket, using the book's [`malt`](https://github.com/themetaschemer/malt)
  library for tensors and automatic differentiation:

  ```
  raco pkg install malt
  racket ch-4.rkt
  ```
